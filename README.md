# 杨星星 · 创意简历与作品集

可直接部署到 GitHub Pages 的静态网站，入口为根目录 `index.html`。

## 部署

上传本目录内全部文件到仓库根目录；在 **Settings → Pages** 选择 **Deploy from a branch**，分支选择 `main`，目录选择 `/ (root)`。`.nojekyll` 已包含，无需构建命令或依赖安装。

## 内容

简历首页、个人简介、专业能力、经历与教育、荣誉奖项、摄影作品筛选与大图浏览、动态影像播放与下载、打印简历。页面使用暖黄相纸、胶卷和底片孔元素，并适配桌面与手机。

AI 影像分组中包含用户提供的《花江峡谷大桥 AI 宣传片》，使用本地 1280×720 视频及视频内实际画面封面；四段视频均可在线播放和下载。

网页上传：单个文件需小于 25 MB。大桥视频采用 720p 双遍编码压缩以适应网页上传限制，码率降低会损失部分细节；原高码率视频未修改。

网页上传专用说明：`assets/huajiang-bridge-ai-720p.mp4` 已压缩至约 21.6 MB，低于 GitHub 网页单文件 25 MB 限制。请上传这个文件，不要上传原始视频或高码率副本。

影像分组：实拍（校园航拍、财大校园空镜）；AI（大桥 AI 宣传片、校园 AI 视频）。
