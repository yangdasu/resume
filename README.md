# 杨星星 · 个人简历与摄影作品集

原生 HTML、CSS、JavaScript 网站，无需安装依赖或构建。照片、视频、校徽均已包含在 assets 中，页面无第三方字体或脚本依赖。

## 本地查看

直接双击 `index.html` 可查看页面。建议在该文件夹运行以下命令，再打开 http://127.0.0.1:4173/ ：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

微信复制需要 localhost 或 HTTPS；直接以文件方式打开时，浏览器可能限制剪贴板，页面会提示手动复制。

## 已实现

- 动态摄影封面、滚动渐入、滚动文字、旋转印章、数据增长动画。
- 12 张摄影作品，分类筛选、展开收起、大图浏览、方向键切换与 Escape 关闭。
- 2 段本地视频，浏览器原生播放控件。
- 响应式手机导航、页面阅读进度、邮件与电话链接、微信复制。
- 动效暂停开关，自动尊重系统的“减少动态效果”偏好。
- “保存简历 / PDF”调用浏览器打印，打印样式保留个人资料、技能、经历、荣誉与联系信息。
- 键盘焦点、跳转正文链接、图片替代文本和对话框焦点管理。

## 部署到 GitHub Pages

将此文件夹内的 `index.html`、`style.css`、`app.js`、`assets/` 和 `.nojekyll` 上传到目标仓库的站点根目录；然后在仓库 Settings → Pages 选择对应分支和根目录。若已使用 GitHub Pages，将文件更新至当前发布目录即可。所有资源路径均为相对路径，支持 `/resume/` 这样的子目录。

当前交付为本地网站，尚未发布到公共互联网，也未修改原有线上站点。

## 修改内容

- `index.html`：个人资料、经历、奖项、联系方式、封面文案及视频。
- `app.js`：摄影作品标题与分类、封面切换文案、交互逻辑。
- `style.css`：色彩、排版、动画、手机布局和打印样式。
- `assets/`：实际照片、视频、校徽与站点图标。
